# 混沌化 SVPWM 电机诊错系统

> 基于 AMD/Xilinx Zynq-7020 FPGA，通过混沌系统动态调制 SVPWM 载波周期，研究开关频谱能量分散特性，为电机状态分析和故障诊断提供可控激励与对比数据。

![项目封面](assets/project-cover.png)

## 项目简介

本项目面向电机驱动过程中的频谱分析与故障诊断需求，在传统三相 SVPWM 的基础上引入 Lorenz 混沌系统。

混沌状态经过定点计算和频率映射后，用于动态改变 SVPWM 的载波周期，使固定开关频率附近的频谱能量向更宽的频率范围分散。工程同时提供无混沌固定载波版本，用于与混沌版本进行波形、频谱、资源占用和时序性能对比。

本项目采用 Verilog HDL 实现，可在 Vivado 2026.1 中进行仿真、综合、实现和 Bitstream 生成。

## 主要功能

- 生成三相 SVPWM 信号
- 支持普通固定载波模式
- 支持 Lorenz 混沌变载波模式
- 混沌载波频率限制在约 4–16 kHz
- 三相电频率固定为 3 Hz
- SVPWM 调制度固定为 8%
- 上下桥臂死区时间为 2 μs
- FPGA 配置完成后自动启动 PWM
- 提供普通版与混沌版 BIT 文件
- 提供仿真、综合、实现和时序报告
- 提供资源占用及频谱对比基础
- 提供可复现构建脚本和工程验证脚本

## 技术原理

系统首先计算三相旋转电压参考，然后通过 SVPWM 模块生成三相 PWM。

混沌版本在此基础上增加 Lorenz 混沌状态迭代模块，并将混沌状态映射为动态载波频率：

```text
Lorenz 混沌状态迭代
          ↓
混沌变量定点化与限幅
          ↓
映射为 4–16 kHz 载波频率
          ↓
动态改变 SVPWM 开关周期
          ↓
生成三相混沌化 PWM
          ↓
开关频谱能量分散
          ↓
为电机状态和故障频谱分析提供数据
普通版本采用固定 10 kHz 载波，混沌版本的开关周期随混沌状态非周期变化。

混沌调制主要改变开关周期及其频谱分布，不直接改变三相旋转电压的基础电频率。

安全说明
本工程中的BIT为自动启动版本。FPGA配置完成并经过内部启动延时后，会自动输出PWM和使能信号。

烧录或修改接线前必须断开电机侧直流电源。

本工程为开环实验系统，目前不包含：
- 相电流闭环控制
- 转子位置闭环
- 堵转检测
- 硬件过流保护
- 驱动板温度保护
- 电机故障后的自动关断
FPGA IO电压为3.3 V，禁止将5 V信号直接输入FPGA。进行桥臂测量时应使用合适的差分测量方式，避免示波器接地夹造成短路。
项目意义
传统固定载波SVPWM的开关频谱通常集中在载波频率及其倍频附近。混沌化载波可以改变每个开关周期的持续时间，使频谱能量分散到更宽的频率范围。

本项目通过普通版和混沌版的对照，为以下研究提供可复现平台：
- 电机PWM频谱分析
- 混沌调制与扩频研究
- 电磁干扰频谱分散研究
- 电机异常状态频谱特征提取
- FPGA实时电机控制算法验证
- 电机诊断与容错方法研究
需要注意：混沌调制不能直接消除缺相、接线错误、电感压降、驱动极性错误、铜损、磁饱和或供电不足等硬件问题。
